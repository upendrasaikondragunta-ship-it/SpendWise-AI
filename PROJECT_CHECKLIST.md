# Release / setup checklist

- [ ] Node.js 20+ installed
- [ ] `npm install` completed
- [ ] `.env` created from `.env.example`
- [ ] Firebase Web config added
- [ ] Firebase Email/Password authentication enabled
- [ ] Firestore created and `firestore.rules` deployed
- [ ] Firebase Admin service account configured server-side
- [ ] Gemini API key configured server-side
- [ ] `npm run typecheck`
- [ ] `npm test`
- [ ] `npm run lint`
- [ ] `npm run build`
- [ ] Vercel deployment environment variables configured
- [ ] Test with a separate demo account before internship presentation
